# Frontend

Realizado con Vite + Vanilla, es una página web sobre una empresa de productos.

## Objetivo

- Home - Página principal (semi estática) / Landing Page (SSR)
- Productos -> Listado de productos (dinámico) - CSR
  - Array de productos
  - Productos/:id - Detalle de producto (dinámico)
- About - Fichero html (SSG)
